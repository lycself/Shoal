# 认识 Shoal：软件导览与第一个项目

Shoal 是一个在个人电脑上运行浅海端到端生态模拟的桌面工作台。它从营养盐、浮游生物一直模拟到大型底栖动物和鱼类，通过一组对照实验来检验“如果改变食物网中的某个环节，海洋生态系统会如何响应”。

本章先介绍软件的研究范围、核心术语和界面布局，随后带你从零开始完成一个完整的北海水柱实验。软件安装与环境配置见下一章[安装与设置](chapter:00-install)。

## Shoal 模拟什么

假设在海上选定一个坐标，从海面到海底取出一根竖直的“水柱”。一年之中，表层海水受日照加热、受风力搅动，冬季又因降温而发生垂直混合；水体中的溶解营养盐供养浮游植物（微藻），浮游植物被浮游动物（如桡足类）摄食，浮游动物又成为鱼类的饵料；死亡生物与排泄物沉降到海底，经细菌和底栖动物分解后再矿化为无机营养盐，重新进入循环。

Shoal 用数值模型逐日求解这根水柱里的物理与生态过程。它主要面向水深不超过 200 m 的**陆架浅海**（如北海、东海、黄海、波罗的海），支持在全球任意陆架海域建立站点。

这种覆盖从无机营养盐到高营养级鱼类的模型称为**端到端模型**（end-to-end model，简称 E2E）。它的特点是把物理环境、浮游生物和鱼类放在同一个双向耦合系统里：任何一个营养级发生变化，效应都会沿着食物网向上和向下传递。关于端到端建模的背景，详见[为什么要把鱼和浮游生物放进同一个模型](chapter:01-why-e2e)。

## 适用问题与边界

新建项目时，软件围绕五类具体的研究问题自动生成对应的对照实验：

| 研究问题 | 实验设计 | 对照方案 |
|---|---|---|
| 该海区一年内水温、营养盐和浮游生物如何演变？ | 单个低营养级模型 | 仅运行物理与浮游生物模块，观察季节循环 |
| 鱼类和底栖动物对浮游生物有多大压制作用？ | 高营养级的下行控制 | 依次加入或移除鱼类和大型底栖动物，对比差异 |
| 更换底层浮游生物模型后，上述结论是否仍然成立？ | 宿主模型对比 | 将同一套高营养级模块分别接入不同低营养级宿主 |
| 鱼类摄食是否需要从浮游生物现存量中实时扣除？ | 耦合方式：单向 vs 双向 | 对比“鱼类不消耗饵料”与“双向物质反馈” |
| 用不同建模框架描述鱼类，结果有何区别？ | 高营养级表示方式：功能群 vs 粒径谱 | 在同一水柱上对比按食性分组与按体重分档的鱼类模块 |

各类实验设计的详细拆解见[五类对照实验设计](chapter:13-designs)。

与此同时，也有必要明确本软件**不适用**的场景：

- **特定商业鱼种的渔情预测**：模型中的鱼类代表“浮游食性鱼类”等功能类群或体重粒级，而非大西洋鳕、鲐鱼等单一物种。
- **具体的渔业捕捞配额核算**：软件用于机制探索与敏感度分析，不直接用于现行渔业管理配额评估。
- **水平环流输运与跨区域洄游**：单点水柱模型仅计算垂向混合与沉降，不包含水平平流及鱼类跨海区迁徙。

## 核心术语速览

后续章节会频繁使用以下几个概念：

- **水柱（water column）**：从海面到海底的一维垂向水体单元，只计算垂向过程，故又称一维模型（见[水柱物理](chapter:02-water-column)）。
- **低营养级（lower trophic levels, LTL）**：食物链中下层，涵盖溶解营养盐、浮游植物、浮游动物、异养细菌及有机碎屑（见[营养盐、浮游植物、浮游动物与碎屑](chapter:04-lower-trophic)）。
- **高营养级（higher trophic levels, HTL）**：食物链上层，在软件中包括鱼类以及生活在海底的大型底栖动物（贝类、多毛类等）。
- **宿主模型（host model）**：负责计算低营养级生物地球化学循环的模型。高营养级模块通过标准接口挂接在宿主模型上运行；软件内置 ERSEM、ECOSMO、ERGOM 三个宿主（见[三个宿主模型](chapter:05-hosts)）。
- **功能群（functional groups）与粒径谱（size spectrum）**：表示高营养级生物的两种建模思路。前者按食性与栖息水层划分固定类群；后者不区分物种，按个体体重划分连续粒级（见[粒径谱](chapter:06-size-spectrum)与[功能群](chapter:07-functional-groups)）。
- **对照实验（controlled experiment）**：在相同站点与气象驱动下，每次只改变一个模型配置或参数，通过运行结果之差分离出该因素的净效应。
- **预热（spin-up）**：由于模型的初始浓度是人为给定的，正式分析前需要先连续循环运行若干年，待各状态变量的年际漂移趋于平缓（达到周期稳态），再截取后续年份用于统计分析。

## 界面布局与页面功能

软件窗口分为五个区域：

| 区域 | 说明 |
|---|---|
| 左侧导航栏 | 按研究工作流从上到下排列各功能页，底部为“入门教程”、“设置”及折叠按钮。拖动右边缘可调整宽度 |
| 顶部菜单栏 | 左侧为文件、运行、视图、帮助菜单；中间显示当前项目名称（点击可切换项目）；右侧为任务队列控制与 AI 助手开关 |
| 中央工作区 | 多数页面采用“左侧列表 + 右侧详情/图表”的分栏结构，左侧面板可通过顶栏按钮折叠 |
| 右侧边栏（按需展开） | 包含 **AI 助手**和**读图说明**面板（点击图表工具栏的书本图标展开，根据当前图表数据生成定量说明） |
| 底部状态栏 | 显示后端连接状态、当前站点坐标、后台任务进度及计算内核版本 |

### 各页面职责

**[项目](app:home)**：项目总览与入口。左侧“研究流程”按顺序列出六个步骤并标注完成状态；右侧展示站点位置、海区适用性说明、近期运行记录及项目列表。

**[站点与物理](app:site)**：配置水柱的物理环境。左栏上方展示经纬度、水深与数据源，下方为**模拟设置**：

- **气象驱动方式**：“重复同一年”循环使用单一年度的气象强迫直至稳态，适合对比不同生态配置；“真实年份”按历史年份顺序连续积分，适合观察年际变化。
- **分析年数与预热年数**：先运行指定年数的预热期，仅保留后续分析年数的输出用于绘图与统计。
- **垂向层数与时间步长**：设置水柱网格层数与积分步长（默认约 1 m 一层、步长 30 分钟）。
- **温盐松弛与营养盐松弛**：一维模型缺少水平海流输运，需以一定时间尺度（单位：天）将温度、盐度和营养盐向 WOA23 气候态剖面轻度松弛，以防长期积分偏离真实水团背景（详见[水柱物理](chapter:02-water-column)）。
- **潮流混合**：通过周期性海面坡度模拟底边界潮流湍流。东海、乔治浅滩等强潮陆架可选“强”，波罗的海、地中海等弱潮海区可选“无潮”。

修改参数后点击左栏顶部的“保存”，将在下一次运行时生效。右侧四个标签页分别展示站点地图、ERA5 日均气象强迫、WOA23 月气候态垂向剖面（虚线标出温跃层或营养跃层深度）以及垂向网格分布。

**[食物网配置](app:foodweb)**：定义生态系统的类群组成与耦合参数。左栏按宿主模型分组列出配置，右侧包含四个标签页：

- **食物网**：按营养级从下到上排列各生物与物质库节点。连线粗细反映捕食偏好，线上流动的光点代表能量传递方向与相对摄食压力。悬停在节点上可高亮其上下游连线；底部复选框可叠加营养盐吸收及排泄碎屑通量。
- **组成**：切换低营养级宿主，开启或关闭大型底栖动物与鱼类模块，选择高营养级框架（E2E 功能群或 MIZER 粒径谱）及耦合方式（单向或双向）。
- **高营养级参数**：查看并修改鱼类和底栖动物的最大摄食率、半饱和常数、同化效率、死亡率等参数。
- **配置文件**：实时预览即将传给计算内核的 `fabm.yaml` 全文。

**[实验与运行](app:experiments)**：管理对照实验与计算任务。左栏上方为实验列表，下方为“全部运行记录”。选中一个实验后：

- 点击“全部运行”将该实验包含的所有配置加入计算队列；全部完成后，按钮变为“对比结果”，点击即可跳转至结果页并自动勾选这组运行。
- 列表中显示每个配置的运行状态、进度与耗时，点击日志图标可查看 GOTM 标准输出；在“全部运行记录”中可下载原始 NetCDF 文件或删除旧记录。
- 点击“参数扫描…”可针对某一配置选定参数与一系列取值，批量生成敏感度实验。

**[结果分析](app:results)**：对比与可视化模拟输出。左栏上方勾选要对比的运行记录（**第一个勾选的运行作为基准**，其余运行均计算相对它的变化），下方按类别筛选输出变量。右侧提供九个分析视图：

| 视图 | 内容 |
|---|---|
| 指标对比 | 汇总各次运行在分析期内的年均关键指标（浮游生物、鱼类、初级生产、海气 CO₂ 通量等）及相对基准的变化百分比 |
| 图版 | 预设排版的多面板组合图：变量 × 运行的时间–深度矩阵、高营养级季节循环、相对基准差异柱状图、多年演变、通量差值图及参数扫描曲线 |
| 时间–深度 | Hovmöller 剖面图，虚线标出混合层底界；点击图中任意位置可查看对应日期的垂向剖面与对应深度的时序曲线 |
| 水柱动画 | 逐日演示全年水温、混合层底界、温跃层与叶绿素峰值深度的垂向变化 |
| 时间序列 | 支持水柱积分、水柱平均、表层或底层时间序列；切换至“年循环”可叠加多年平均季节曲线及极值标注 |
| 垂向剖面 | 对比指定月份（如冬、春、夏、秋）的垂向分布曲线 |
| 粒径谱 | 展示 MIZER 各体重粒级的鱼类生物量、丰度密度及随时间的演变（仅在含粒径谱的运行中显示） |
| 食物网状态 | 在食物网拓扑图上叠加分析期各节点的年均生物量与实测摄食压力 |
| 验证与稳态 | 检验预热期后各状态变量的年际漂移率，并与 WOA23 月气候态对比偏差、RMSE、相关系数及泰勒图 |

所有图表均可通过右上角相机图标导出 3 倍分辨率 PNG，支持框选放大与双击还原。

**[三维陆架](app:shelf)**：在指定经纬度范围内生成二维网格，每个海洋格点运行一根独立的一维水柱，汇总绘制空间分布图、分区统计表、水柱集合逐月走势及三维地形柱状图。点击地图上的任意格点可查看单点详情与季节循环，或直接以该坐标创建一维项目（详见[从一根水柱到整片陆架](chapter:11-shelf-3d)）。

## 第一个项目：完整操作示例

下面通过一个具体实验熟悉完整流程：**在北海中部站点，检验鱼类和大型底栖动物对浮游动物的下行控制有多强，以及能否单纯用“把浮游动物死亡率调高 20%”来近似替代鱼类的捕食。**

### 第 1 步：新建项目

在[项目](app:home)页点击“新建项目…”（`Ctrl+N`），按以下四项设置：

1. **研究海区**：在“常用海区”下拉列表中选择“北海中部（模型标定站点）”（56°N 3°E，水深 73 m），或直接在地图上点选海域。北海中部是典型的温带季节性层化陆架海，也是两篇核心参考文献的基准测试点。
2. **气象年份**：起止年份均保持默认的 `2014`，软件将循环使用 2014 年的气象强迫进行稳态模拟。
3. **要研究的问题**：勾选“高营养级的下行控制”。
4. **低营养级模型（宿主）**：初次尝试可仅勾选 `ECOSMO`（变量较少、计算最快）。

对话框底部提示将生成 5 个配置：

| 配置名称 | 含义 |
|---|---|
| ECOSMO 仅低营养级 | 仅包含浮游生物与营养盐循环，作为对照基准 |
| ECOSMO + 大型底栖 | 在低营养级基础上接入大型底栖动物 |
| ECOSMO + 鱼类 | 在低营养级基础上接入两类鱼类功能群 |
| ECOSMO + 鱼类 + 底栖（完整） | 同时接入鱼类与大型底栖动物 |
| ECOSMO 浮游动物死亡率 +20% | 不加高营养级，仅将浮游动物闭合死亡率上调 20% |

若当前处于无网络环境，可勾选对话框底部的“没有网络：使用离线算例”，软件将改用内置的北海北部 PROVESS 1998 算例数据完成后续步骤。

### 第 2 步：构建站点强迫数据

点击“创建项目”后，后台开始下载并构建该站点的三项数据（约需 1–3 分钟，下载后自动缓存至本地）：

| 数据源 | 内容 | 用途 |
|---|---|---|
| ERA5 再分析 | 逐小时气温、风速、云量、太阳短波辐射、气压与降水 | 驱动海表热通量与风生湍流混合 |
| WOA23 气候态 | 世界海洋图集 2023 版月均温度、盐度、硝酸盐、磷酸盐、硅酸盐与溶解氧剖面 | 提供初始垂向剖面与侧向松弛目标 |
| ETOPO 2022 | 全球海底地形高程数据 | 获取站点水深 |

构建完成后，可打开[站点与物理](app:site)查看驱动数据：在“气象强迫”中观察冬夏风速与辐射的季节对比；在“气候态剖面”中选择温度，可以看到夏季上暖下冷、中间被温跃层隔开，而冬季整根水柱上下混合均匀。

### 第 3 步：运行对照实验

进入[实验与运行](app:experiments)，选中“下行控制 · ECOSMO”，点击“全部运行”。5 个配置将按本机并行数排队计算。默认的快速设置包含 4 年预热与 1 年分析，单次运行在普通笔记本电脑上约需十几秒至半分钟。

全部运行结束后，右下角会弹出完成通知，点击“对比结果”即可进入结果分析页。

### 第 4 步：查看与解读结果

结果页左侧已自动勾选全部 5 次运行，排在第一位的“ECOSMO 仅低营养级”作为基准：

1. **时间–深度剖面**：在左下变量列表中选择“温度”，观察春末温跃层的建立与秋季混合层的加深；再切换至“硅藻”，查看春季水华暴发的时间与水层。
2. **指标对比**：查看汇总表中“中型浮游动物”一行的相对变化，对比“完整”配置与“浮游动物死亡率 +20%”对浮游动物年均生物量的压低幅度。
3. **季节循环**：切换至“时间序列 → 年循环”，选择“中型浮游动物”。对比“完整”与“+20%”两条曲线：不仅看峰值高低，还要看峰谷出现的月份是否发生了偏移。在北海中部的模拟中，显式引入鱼类和底栖动物不仅压低了浮游动物生物量，还会改变其季节消长节奏，这是固定上调死亡率系数无法重现的（Vijayakumaran 等，2026）。
4. **食物网状态**：选择“完整”运行，直观查看能量主要沿哪几条路径流向鱼类与底栖动物。
5. **验证与稳态**：切换到“验证与稳态”检查预热期是否充足。由于默认快速设置仅预热 4 年，世代周期较长的鱼类和底栖动物通常尚未完全收敛；正式研究时可在“站点与物理”页将预热年数增至 15–20 年后重跑。

### 第 5 步：修改参数与参数扫描

若想进一步测试“鱼类死亡率加倍（例如捕捞加剧）会带来什么变化”：

1. 在[食物网配置](app:foodweb)页选中“ECOSMO + 鱼类 + 底栖（完整）”，点击“另存为”创建副本（如命名为“鱼 1 死亡率加倍”）。
2. 在“高营养级参数”标签页将鱼 1 的死亡率 `m` 乘以 2，点击“保存”并“运行”。
3. 回到结果页，勾选原“完整”配置与新配置即可直接对比。若想系统考察某一参数在连续区间内的影响，可使用实验页的“参数扫描…”功能，并在“图版 → 参数扫描响应”中查看各指标的弹性排序。

## 常见故障排查

| 现象 | 排查方法 |
|---|---|
| 站点构建失败 | 检查网络连接（需访问 Open-Meteo 与 NOAA 服务器），稍后在站点页点击“重新构建”，或改用内置离线算例 |
| 点选地图提示“陆地” | 所选坐标在 ETOPO 地形中海拔高于海面，请移至离岸更远的浅海格点 |
| 模型运行失败 | 点击实验页该运行右侧的日志图标查看末尾报错，常见原因为参数修改过于极端导致数值发散 |
| 结果存在明显年际漂移 | “验证与稳态”中的年均曲线尚未走平，需在“站点与物理”页增加预热年数 |
| 某项指标显示为空 | 当前配置不包含对应生物类群（如无鱼基线中没有鱼类生物量） |
| 计算内核未就绪 | 桌面安装包用户请重新安装；源码运行用户请先在终端执行 `pnpm kernel` 编译内核 |

## 使用注意事项

- **单点水柱的物理代表性**：一维模型假设水柱在水平方向均匀，平流与陆源输入仅通过向 WOA23 气候态松弛来近似。
- **相对变化优先于绝对值**：受一维简化和参数不确定性影响，对照实验中“处理组相对于基准组的差值或百分比变化”比单次运行的绝对数值更具参考价值。
- **基准运行的选择**：结果页的所有百分比变化均相对于左侧列表中**第一个勾选的运行**计算；如需更换基准，可先点击“清空”再按顺序重新勾选。
- **项目的安全删除**：删除项目时，文件夹会先移入工作区的 `trash/` 目录，需要时可手动移回 `projects/` 恢复。

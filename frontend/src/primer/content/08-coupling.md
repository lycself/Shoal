# 单向与双向耦合：鱼会不会把食物吃少

将高营养级模型（HTL：鱼类与大型底栖动物）与低营养级模型（LTL：营养盐、浮游植物、浮游动物、细菌和碎屑）连接起来时，核心选择在于**鱼类的摄食与排泄是否反过来改变低营养级状态**：

- **单向耦合（one-way / offline coupling）**：信息只从低营养级流向高营养级。高营养级模块在每个时间步读取浮游生物浓度和水温来计算摄食与生长，但被吃掉的生物量不从浮游生物中扣除，排泄物也不返回水体。这种接法包含自下而上的**上行控制**（bottom-up），但切断了自上而下的**下行控制**（top-down），因此无法模拟“鱼类变化 → 浮游动物变化 → 浮游植物变化”的营养级联。
- **双向耦合（two-way / online coupling）**：高低营养级在每个时间步同步交换物质通量（例如西北欧陆架三维模拟中每 5 分钟交换一次；Powley 等 2026）。鱼类摄食直接消耗浮游生物，其粪便、排泄物和呼吸产物实时返回碎屑、无机营养盐和溶解无机碳库。

在下方实验台中依次切换“无鱼”“单向”“双向”，对比浮游动物峰值高度、出现时间以及鱼类生物量的变化。

## 双向耦合交换的物质通量

在双向耦合运行中，高营养级模块与低营养级宿主之间在每个时间步交换以下通量：

| 通量类别 | 方向 | 粒径谱模块（MIZER，接 ERSEM） | 功能群模块（E2E，接三个宿主） |
|---|---|---|---|
| 捕食损失 | 浮游生物 → 鱼 / 底栖 | 从 P1–P4、Z4–Z6 的碳、氮、磷、硅中按猎物组分比例扣除 | 从所连接的各猎物变量中扣除 |
| 排粪与死亡颗粒 | 鱼 / 底栖 → 碎屑 | 进入大粒级颗粒碎屑 R8 | 颗粒部分（$1-\alpha_{DOM}$）进入水体碎屑（鱼）或海底沉积物（底栖）；溶解部分（$\alpha_{DOM}$）进入 DOM |
| 无机氮磷排泄 | 鱼 / 底栖 → 营养盐 | 进入铵盐 N4、磷酸盐 N1 | 进入铵盐、磷酸盐 |
| 呼吸碳释放 | 鱼 / 底栖 → 碳酸盐 | 进入溶解无机碳 DIC（O3） | 物质收支修正版进入宿主 DIC（宿主含 DIC 时） |
| 呼吸耗氧 | 溶解氧 → 鱼 / 底栖 | 每呼吸 1 mol C 消耗 $127/106\ \mathrm{mol\ O_2}$ | 修正版每排泄 1 mol C 消耗 $1\ \mathrm{mol\ O_2}$ |
| 仔鱼补充 | 碎屑 → 最小鱼档 | 从 R8 提取补充鱼苗所需的碳、氮、磷 | 无独立补充项 |
| 捕捞移除 | 鱼 → 系统边界外 | 80 g 以上鱼类被捕捞上岸，离开生态循环 | 官方代码不含捕捞项 |

由于鱼类的生物量或摄食总量按整根水柱深度积分计算，而浮游生物按深度分层分布，上述通量需要按垂向分布权重分配回各个水层：MIZER 按全体浮游生物猎物总浓度的垂向比例分配（见[粒径谱一章](chapter:06-size-spectrum)），E2E 则按每种猎物各自的垂向浓度比例扣除（见[功能群一章](chapter:07-functional-groups)）。

## 多元素质量守恒

双向耦合要求每一笔跨模块通量都在源变量和汇变量上成对记账，从而保证碳、氮、磷、硅四元素的质量守恒。

以 MIZER 为例，当鱼类群落摄食含有 $100\ \mathrm{mmol\ C}$ 的浮游生物（并按猎物当前化学计量比带入相应的氮和磷）时：

1. **排粪（30%）**：$30\ \mathrm{mmol\ C}$ 及同比例的氮、磷排入大颗粒碎屑 R8；
2. **呼吸与排泄（50%）**：$50\ \mathrm{mmol\ C}$ 转化为溶解无机碳（DIC），消耗约 $60\ \mathrm{mmol\ O_2}$，同比例的氮、磷以铵盐和磷酸盐形式释放回水体；
3. **同化与生长（20%）**：$20\ \mathrm{mmol\ C}$ 进入同化池。由于鱼体维持固定的 Redfield 比（C:N:P = 106:16:1），若同化池中的氮或磷不足以匹配全部 $20\ \mathrm{mmol\ C}$，实际生长量由最紧缺的元素决定，多余的碳和其他元素作为颗粒物排入 R8。

仔鱼补充所需的碳、氮、磷同样从 R8 中等量扣除。系统唯一的质量净流出是渔获上岸量（landings），在真实陆架海中这一流出由河流输入和外海交换补充（Powley 等 2026）。

## 为什么单向耦合的参数不能直接用于双向耦合

将单向耦合模型改造成双向耦合时，如果直接沿用单向条件下率定的参数，模型往往会出现严重的种群崩溃。原因主要有三点：

**1. 单向耦合容易高估鱼类的搜寻率（清除率）。** 在单向耦合中，无论鱼类吃掉多少浮游生物，下一步的饵料浓度都不会减少。因此即便采用偏高的搜寻率参数，模拟出的鱼类生物量依然合理。一旦切换到双向耦合，同样的高搜寻率会将中型浮游动物过度消耗，进而导致鱼类因食物断绝而崩溃。在西北欧陆架三维模拟中，测试的多组文献搜寻率参数大多导致中型浮游动物和鱼类崩溃，最终采用基于 Acuña 等 (2011) 观测重新拟合的较低搜寻率参数才使系统稳定共存（Powley 等 2026）。

**2. 原有浮游动物闭合项会造成捕食损失被重复计算。** 无鱼的低营养级模型通过浮游动物闭合项（如额外死亡率或种内捕食）隐式代表鱼类捕食。加入显式鱼类并开启双向反馈后，如果不相应调低或关闭原闭合项，浮游动物就会同时承受闭合项和鱼类捕食两份损失。因此，ERSEM–MIZER 双向配置关闭了中型浮游动物 Z4 的种内捕食、基础死亡和越冬死亡（仅保留缺氧死亡；Powley 等 2026），而 ECOSMO E2E 则将浮游动物背景死亡率下调至原值的 80%（Daewel 等 2019）。

**3. 捕食响应的时间滞后改变了浮游生物物候。** 在无鱼的 ERSEM 基线中，Z4 的种内捕食与 Z4 自身生物量完全同步——Z4 一增加，种内捕食损失立刻同步上升。而在双向耦合中，春季新增的鱼苗需要先经历一段生长时间才能长到大量捕食 Z4 的体型。由于早春捕食压力较小，Z4 在春季增长更快、峰值更高且出现时间提前，随后在夏季被长大的鱼群迅速压低。

使用下方的箱式模型实验台可以直观验证上述机制：依次对比“无鱼”“单向”“双向”，并尝试在“双向”模式下不调低浮游动物闭合死亡率，观察浮游动物与鱼类的演变。

## 调高浮游动物死亡率能否替代显式鱼类

既然闭合项代表高营养级捕食，那么不引入鱼类模块，只把浮游动物的闭合死亡率提高 20%，能否起到与显式鱼类相同的作用？

北海中部的一维对照实验专门对比了“仅低营养级”“浮游动物死亡率 +20%”与“完整配置（显式鱼类 + 大型底栖动物）”（Vijayakumaran 等 2026）。结果表明：

- 单纯将浮游动物死亡率提高 20% 只能使浮游动物生物量在全年按比例降低，**不改变其季节演替形态**；
- 显式引入鱼类和大型底栖动物后，不仅对浮游动物的压制幅度更大，而且**改变了浮游动物的季节峰值时间**，进而改变了浮游植物水华的时间与幅度。

此外，鱼类与大型底栖动物对低营养级的影响具有**非可加性**（1 + 1 ≠ 2）：鱼类捕食大型底栖动物，同时两者又共同竞争碎屑和浮游动物，因此“同时加入鱼和底栖动物”对浮游生物的净效应不等于“只加鱼”与“只加底栖动物”两项效应的简单相加（详见[下行控制与宿主对比一章](chapter:10-paper2)）。

## 在 Shoal 中的配置方法

- **双向耦合（默认）**：FABM-MIZER 中参数 `feedback: true`，E2E 功能群默认即开启双向反馈。
- **单向耦合**：在 FABM-MIZER 中设置 `feedback: false`。此时鱼类模块在线读取 ERSEM 猎物浓度并生长，但不向 ERSEM 写回任何捕食、排泄或呼吸源汇项，ERSEM 的演化与无鱼基线完全一致。
- **闭合项联动调整**：在“耦合方式：单向 vs 双向”实验设计中，双向配置自动将 ERSEM 中 Z4 的种内捕食（`suprey`）、基础死亡（`sd`）和越冬死亡（`mort`）设为 0；在“高营养级的下行控制”实验设计中，ECOSMO 接入高营养级时自动将浮游动物死亡率乘以 0.8，而“浮游动物死亡率 +20%”配置则在不加鱼的情况下将宿主浮游动物死亡率乘以 1.2。

## 深入一点：参数对比与通量量级

**搜寻率重标定。** MIZER 搜寻率公式为 $V(w) = \gamma\, w^{q}$。文献早期参数取 $\gamma = 156\ \mathrm{m^3\,yr^{-1}\,g^{-q}}$、$q = 0.9262$（Blanchard 等 2009）；双向耦合重拟合参数取 $\gamma = 91.32$、$q = 0.776$（Powley 等 2026）。代入具体体重对比：对于 $1\ \mathrm{g}$ 的鱼，搜寻率降低了约 41%；对于 $100\ \mathrm{g}$ 的鱼，由于幂指数 $q$ 减小，搜寻率从约 $1.1\times10^{4}\ \mathrm{m^3\,yr^{-1}}$ 降至约 $3.3\times10^{3}\ \mathrm{m^3\,yr^{-1}}$，仅为原参数的 29%。

**浮游动物被捕食通量。** 在西北欧陆架三维双向模拟中，北海中型浮游动物因鱼类捕食产生的平均日死亡率约为 $0.048\ \mathrm{d^{-1}}$（范围 $0.008\text{–}0.19\ \mathrm{d^{-1}}$），全年被鱼类摄食的通量约为 $15.5\ \mathrm{g\,C\,m^{-2}\,yr^{-1}}$，高于早期离线估计值（约 $5.7\ \mathrm{g\,C\,m^{-2}\,yr^{-1}}$；Maar 等 2014；Powley 等 2026），这与 MIZER 采用无饱和上限的线性功能响应及全年持续捕食有关。

## 常见误区

- **认为双向耦合只是微调，不影响量级。** 在西北欧陆架模拟中，由单向改为双向耦合后，陆架平均鱼类生物量下降约 17%，渔获上岸量下降约 37%，海–气 CO₂ 吸收量下降约 7%（Powley 等 2026；详见[鱼的反馈要不要算一章](chapter:09-paper1)）。
- **认为系统总质量守恒意味着鱼类不影响碳循环。** 双向耦合虽然保证总碳守恒，但改变了碳在浮游生物、溶解有机碳、颗粒碎屑和无机碳库之间的分配比例与周转速度，从而改变了海–气 CO₂ 通量。
- **在线 `feedback: false` 运行仍需留足预热时间。** 虽然 `feedback: false` 在机制上等价于用基线浮游生物离线驱动鱼类模型，但在线运行中鱼类从较低的初始值（约 $0.6\ \mathrm{g\,WM\,m^{-2}}$）起步，需要多年积分才能让大体重档达到稳态。
